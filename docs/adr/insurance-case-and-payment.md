# ADR 0003 — 보험 사건·청구·수령을 분리

상태: 설계 채택 · 날짜: 2026-10-17 · 구현 검증 전

## 배경

하나의 치료가 여러 외래/입원/약국을 포함하고 여러 보험계약에서 나눠 지급될 수 있다.

## 결정

사건은 계약과 독립, 진료는 tree, 비용은 원본, 청구는 다중 근거, 실제 지급은 원본+사건별 배분으로 모델링한다.

## 결과와 비용

다중 청구에도 중복 집계를 피하고 청구 없는 직접 지급 기록이 가능하다. 대신 배분합계·반환 검증을 트랜잭션에서 수행해야 한다.

## 검증

관련 요구사항의 인수 기준과 보안 게이트를 따른다. 결정 변경은 새 ADR로 기록하고 기존 문서를 무단 삭제하지 않는다.
