# 디자인 시스템·사용성 원칙

모바일에서 빠르게 확인·입력하고 PC에서 넓게 비교한다. 금융은 금액의 위계, 가전·소모품은 오늘의 관리 상태, 보험·기록은 관련 원본을 함께 읽는 구조를 중심으로 설계한다. 모든 영역에서 같은 탐색·버튼·상태·입력 규칙을 쓴다.

## 구현 토큰

`apps/client/src/styles.css`의 CSS 변수를 기준으로 한다. 밝은 화면은 배경 `#f5f7f9`, 표면 `#ffffff`, 본문 `#1d2937`, 보조 글자 `--muted #5b6a7b`, 입력 테두리 `--border-strong #7a8898`, 강조 `#22675f`다. 다크 모드의 입력 테두리는 `#677d70`이다. 입력 테두리는 표면·배경과 각각 3:1 이상, 보조 글자는 선택 표면(`--selected`) 위에서도 4.5:1 이상이어야 하며 `tests/design-refresh.spec.ts`가 두 테마에서 계산해 확인한다. 생활 관리의 따뜻한 색과 보험 기록의 보라색은 아이콘·상태·구획에 제한적으로 사용한다. 경고·오류·성공은 색과 설명을 함께 표시한다.

카드는 16px, 입력·버튼은 9~10px 모서리를 사용한다. 기본 본문은 15px, 필드·목록 설명은 12~14px이며 보조 글자도 12px(`.75rem`)보다 작게 줄이지 않는다. 화면 제목은 25~32px, 홈 순자산은 30~44px 범위다. 금액은 고정폭 숫자와 정수 원 단위 문자열을 유지하며 큰 수를 임의로 축약하거나 Number로 변환하지 않는다. 한글 글꼴은 로컬에 포함한 Pretendard Variable v1.3.9를 기본으로 사용하고 외부 폰트 요청을 추가하지 않는다. 기본 OS 글꼴은 로드 전 대체 글꼴이며 `font-display: swap`을 적용한다.

시스템 다크 모드에서 별도 표면·본문·테두리·경고 토큰을 적용한다. 애니메이션은 짧은 상태 전환과 로딩 표시로 제한하고 동작 줄이기 설정을 따른다. 코드에서 화면을 스크롤할 때도 `shared/motion.ts`의 `scrollBehavior()`로 동작 줄이기 설정에서는 즉시 이동한다. 아이콘은 `shared/Icon.tsx`의 직접 작성한 SVG를 사용하며 장식 아이콘은 접근성 트리에서 제외한다.

## 레이아웃과 정보 위계

- 좁은 화면은 단일 열과 하단 5개 메뉴, 1120px 이상은 244px 사이드바와 본문을 사용한다. 로그인·가계 시작 화면은 별도 집중형 배치를 사용하며 뒤로·홈 이동은 유지한다.
- 홈 상단은 월간 자산 다음 오늘 기준 소모품 순서다. PC에서는 두 카드를 나란히 배치한다. 모바일에서는 장식 설명과 여백을 줄여 핵심 카드가 먼저 보이게 한다.
- 자산 카드의 순자산·증감·총자산·부채·확인 상태는 바로 표시한다. 범위·지분 변경과 기준일 주의도 접지 않는다. 이전 순자산, 동일 범위 변화, 증감률과 자세한 기준은 펼쳐 확인한다.
- 자산 목록은 등록 상태와 소유자를 먼저 보여 준다. 반복되는 금액 미조회 안내는 목록 위에 한 번 표시하고, 지분·보유기간은 항목에서 펼친다. 필터는 적용 조건 수가 보이는 펼침 영역에 둔다. 월별 평가액을 목록 조회만으로 만들어 표시하지 않는다. 자산·계좌 상세의 금액은 같은 자산 ID와 선택 월 스냅샷을 조회하며 가계 보유분을 주 금액으로 둔다. 자산 탭의 이번 달 기록 진입은 선택한 과거 월과 별도로 서울 현재 월을 가리킨다.
- 자산·계좌의 공통 기본정보 폼은 자산 종류, 소유·반영 기준, 보유기간의 세 구역으로 나눈다. PC에서는 설명과 입력을 나란히 놓고 모바일에서는 순서대로 읽는다.
- 보험 사건은 사건 정보와 실제 비용·순부담, 진료 트리와 비용 원본, 청구와 실제 지급을 각각 묶는다. 넓은 화면에서 두 열을 쓰고 좁은 화면에서는 같은 읽기 순서로 쌓는다.
- 표는 자체 가로 스크롤 영역에 넣는다. 긴 텍스트와 큰 금액은 화면 전체를 가로로 밀지 않도록 줄바꿈한다. 목록·표·차트는 기존 API 원본과 계산 규칙을 그대로 사용한다.

1000px 이상 월 기록·항목별 비교는 정렬 가능한 표로, 좁은 화면에서는 같은 자료의 카드로 렌더링한다. 숨겨진 복제 폼을 만들지 않는다.
금액 열은 우측 정렬한다. 월 기록은 등록 순·이름 순·가계 보유분 큰 순을 제공하고 미입력은 마지막이다.
비교는 같은 대상 → 지분 변경 → 범위 추가·제외 → 비교 대기·참고 항목 순으로 나눠 기본 이름 순으로 보여 준다.
변화 큰 순은 각 묶음 안에서 서버 `net_assets_effect_krw`의 정수 절댓값을 사용한다. 부채 감소는 순자산 증가,
범위 편입·제외는 저축·소비와 구분한다. 비교 불가 금액은 0원으로 바꾸지 않고 해당 묶음의 마지막에 둔다.

웹 파비콘과 Android adaptive icon·스플래시는 기존 책 SVG 도형과 강조색 `#22675f`를 공유한다.
Android 최소 API 30에 맞는 벡터 자산으로 기본 템플릿 PNG를 대체했다. 실제 기기의 설치 아이콘·시작 화면 인수는 별도로 수행한다. [구현 검증](testing/desktop-finish.md)에 결과를 기록한다.

## 입력·상태·접근성

버튼·입력·주요 탐색 링크·구간 선택 버튼의 높이는 최소 48 CSS px로 설계한다. 예외로 480px 이하 홈 자산 카드의 기간 선택 버튼은 34px로 남아 있으며 후속 정리 대상이다. 작은 인라인 링크는 주변 여백과 문맥을 유지한다. 네이티브 화면의 dp와 실제 오탭·TalkBack 검증은 별도 실기기 게이트다. 키보드 포커스, 본문 건너뛰기, 펼침의 기본 키보드 동작, 비활성화·로딩·오류 재시도 상태를 유지한다.

포커스 복귀: 다른 화면으로 이동하면 본문(`main`)에 초점을 둔다. 뒤로가기로 돌아오면 목록 위치와 불러온 페이지 수를 복원한다(메모리에만 두고 저장하지 않는다). 월 기록의 행 편집을 저장·취소하면 그 행 버튼으로, 행이 사라졌으면 값 목록 제목으로 초점을 돌린다. 메뉴는 현재 화면 링크에만 `aria-current="page"`를, 하위 화면을 보는 동안 상위 구역 링크에는 `aria-current="true"`를 둔다. 가로 스크롤 표는 이름 있는 `region`으로 감싸 키보드로 스크롤할 수 있게 한다.

문구 규칙:

- 입력 내용을 버리는 버튼은 `입력 취소`다. 검토·안내 패널을 닫는 버튼은 `<무엇> 검토 닫기`다. 진행 중인 요청 중단(`요청 대기 중단`)과 기록 동작 이름(`배분 연결 취소` 등)은 그대로 둔다.
- 한 화면의 여러 구역이 함께 실패하면 각 구역의 재시도 대신 첫 오류 문구 하나와 재시도 버튼 하나(`shared/RetryFailed.tsx`)를 보인다. 버튼은 실패한 구역을 모두 다시 불러온다. 한 구역만 실패하면 그 구역의 재시도를 그대로 보인다.
- 금액 입력 오류는 저장 버튼을 미리 막지 않는다. 저장을 누르면 필드 아래에 이유를 보이고 첫 오류 필드로 초점을 옮긴다.

빈값과 0원, 전월값 미확인, 월 기록 없음, 작성 중을 구분한다. 확인되지 않은 값을 실제 잔액·총 소비·저축액·확정 보험금으로 표시하지 않는다. 잠금·인증·보관함의 동작과 비밀 처리 경계는 시각 디자인과 분리한다. 보안 화면을 여는 버튼은 평문을 받지 않는다.

공통 UI는 MoneyInput, MonthPicker, OwnershipPicker, PaymentMethodPicker, VerificationBadge, StatusChip, AmountBreakdown, LinkedResourceCard, MedicalTree, AllocationEditor, StockActionDialog, SecureActionButton, ConflictDialog, EmptyState, ErrorRetry, AuditTimeline의 역할로 확장한다. 이 목록 전체가 이미 독립 컴포넌트로 구현됐다는 뜻은 아니다.

## 참고와 검증

구조 참고는 [shadcn/ui Dashboard](https://ui.shadcn.com/blocks/dashboard-01), [Sidebar](https://ui.shadcn.com/blocks/sidebar-07), [Login](https://ui.shadcn.com/blocks/login-03)이다. 해당 프로젝트는 [MIT 라이선스](https://github.com/shadcn-ui/ui/blob/main/LICENSE.md)이며 이번 변경은 배치 원칙을 참고해 직접 구현했다. 외부 컴포넌트 소스·아이콘·이미지·패키지를 복사하거나 추가하지 않았다. 글꼴은 별도로 [Pretendard 공식 배포](https://github.com/orioncactus/pretendard/tree/v1.3.9)를 사용한다.

합성 데이터로 PC·모바일 화면, 좁은 화면과 200% 글꼴, 다크 모드, 긴 이름·큰 금액, 빈 상태·오류·로딩을 확인한다. 실행 결과와 한계는 [디자인 개편 검증 기록](testing/design-refresh.md)에 남긴다. 스크린샷은 서버 권한·암호화·실기기 검증을 대신하지 않는다.
