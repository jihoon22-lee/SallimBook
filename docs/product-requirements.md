# 제품 요구사항 · v1.0.0

상태: 기능 범위 확정, 세부 구현 검증 전. 기준일: 2026-10-17.

## 1. 목적과 대상

부부가 월별 자산 상태를 확인하고, 정기 납부와 보험 사건·생활 물품을 공동 관리한다.
개별 거래를 빠짐없이 수집해야만 쓸 수 있는 제품을 만들지 않는다.
주 사용은 Android 앱이고, PC 웹에서도 동일한 핵심 기록을 보고 편집한다.
기능의 간단함을 이유로 필수 영역을 다음 버전으로 임의 이월하지 않는다.

## 3. 명시적인 비목표

v1에서 문자/다른 앱 알림 자동 수집, 오픈뱅킹·마이데이터 연동, 상세 카드/은행 거래 가져오기,
자동 소비 분류, OCR·AI 약관/보험금 산정, 실시간 시세, 자동 이체/결제, iOS, 다가계 SaaS,
투자 매매·정교한 수익률, 완전한 오프라인 편집 동기화는 제공하지 않는다.

의료비·보험금·고정 납부의 수동 기록은 위 제외 조건에 해당하지 않는다.
초기부터 필요한 **제한된 금전 이벤트**이며 전체 입출금 장부라고 표시하지 않는다.

## 4. 주요 사용자 여정

### 월별 확인

자산/계좌 등록 → 첫 기준월 금액 입력 → 다음 달 전월값 불러오기 → 바뀐 금액 입력 또는 동일 확인 → 확정 → 비교.
기존 보유 자산의 뒤늦은 등록은 실질 증가와 구분한다. 월중 기록은 월말 잔액으로 위장하지 않는다.

### 정기 납부

보험 또는 구독 등록 → 결제수단 연결 → 회차별 예정 생성 → 실제 납부일/금액 확인 → 월별 요약.
보험료 변경은 미래 회차에 적용하고 과거 납부액은 그대로 남긴다.

### 의료 사건

질환/수술 사건 생성 → 외래·입원·수술·약국 노드 추가 → 실제 지불금 및 문서 등록 → 관련 계약에 청구 → 지급 기록.
청구 상세를 모르는 경우 사건에 보험금 수령부터 입력 가능해야 한다.

### 카드 확인

카드 선택 → 마스킹 상태 → 보호된 전체 정보 보기 → 인증 → 제한 시간 표시 → 이탈/백그라운드 전환/타임아웃 잠금.
Android 로컬 CVC는 해당 기기에서만 표시한다. 선택적 공유 CVC와 번호·유효기간은 PC에서 보관함 암호로 해제할 수 있다. 공유 저장은 별도 동의를 받는다.

### 소모품

제품 등록 → 소모품 연결 → 구매한 수량 입고 → 사용 시 교체 → 재고 감소·다음 확인일 변경.
구매일과 교체일은 독립이다.

## 5. 출시 정의

R-01~R-22와 모든 필수 보안 게이트를 충족하는 하나의 v1.0.0을 출시한다.
마일스톤은 작업 구분이지 필수 기능을 제외한 별도 정식 출시를 뜻하지 않는다.
로컬 CVC는 Android 네이티브의 명시적 저장 동의와 매회 강한 생체인증을 요구하는 선택 기능이다. 공유 CVC는 웹/Android 전용 보관함에서 명시적 동의 후 v2 암호문으로 저장한다. [변경 결정](adr/web-cvc-vault-v2.md).
2026-10-18 사용자 결정으로 실기기 시험은 사용자 후속 작업이며 결과 제출을 개발·배포 조건으로 삼지 않는다.
[활성화 결정](adr/local-cvc-release-option.md)과 [검증 수준](testing/local-cvc-release.md)을 구분하고 미실행 시험을 통과로 쓰지 않는다.
