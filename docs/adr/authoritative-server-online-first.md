# ADR 0005 — 공동 서버 기준·온라인 우선

상태: 설계 채택 · 날짜: 2026-10-17 · 구현 검증 전

## 배경

부부의 동시 수정과 금액 정확성이 중요하고 오프라인 복잡성은 초기 가치보다 크다.

## 결정

서버 기준 기록, version 충돌, idempotency, 메모리 캐시를 사용한다. 영구 오프라인 편집/동기화는 후속이다.

## 결과와 비용

충돌·재시도를 명확하게 처리한다. 인터넷 단절 시 수정 성공을 보장하지 않고 실제 저장 여부를 표시한다.

## 검증

관련 요구사항의 인수 기준과 보안 게이트를 따른다. 결정 변경은 새 ADR로 기록하고 기존 문서를 무단 삭제하지 않는다.
