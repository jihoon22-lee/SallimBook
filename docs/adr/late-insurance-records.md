# ADR 0009 — 종료 계약의 사후 청구·지급 기록

상태: 채택 · 날짜: 2026-10-20 · 자동 시험 검증, 실기기 미확인

## 배경

보험 청구와 보험금 입금은 진료보다 늦게 기록되는 경우가 많다. 계약이 해지·만기·실효된 뒤에도
종료 전 진료에 대한 청구를 접수하거나 이미 받은 보험금을 뒤늦게 입력해야 한다.
기존 구현은 새 청구와 청구 없는 직접 배분에서 사용 중인 계약만 허용해, 실제로 받은 돈을 기록할 수 없었다.

## 결정

종료·실효 계약에도 새 청구와 청구 없는 직접 배분을 허용한다(사용자 결정 2026-10-19).
계약 상태는 화면의 안내로만 보이며 기록을 막지 않는다. 다른 가계의 계약은 지금처럼 404다.
계약 상태 변경이 과거 청구·지급 원본을 바꾸거나 숨기지 않는다.

함께 정한 표시 규칙: 사건 요약 상단은 기존 화면 명세대로 의료 지불금·환불·순의료비·순보험금·순현금부담 5개 수치를 이 순서로 보여준다(M11).

## 결과와 비용

사용자는 계약 종료 뒤에도 실제 청구·입금을 빠짐없이 기록할 수 있다. 대신 종료일 이후 진료를 잘못 연결해도 서버가 거부하지 않으므로
화면은 선택한 계약의 상태를 계약 선택 옆에 안내한다. 보장 가능성이나 지급 적정성은 앱이 판단하지 않는다.

## 검증

`test_inactive_policy_accepts_late_claim_and_direct_allocation`(DB)과 계약 선택 안내 브라우저 시험이 종료 계약의
청구·직접 배분 저장과 안내 문구를 확인한다. 다른 가계 계약의 404는 기존 권한 시험이 유지한다.
결정 변경은 새 ADR로 기록하고 기존 문서를 무단 삭제하지 않는다.
