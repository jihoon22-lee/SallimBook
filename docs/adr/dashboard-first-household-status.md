# ADR — 등록 기록 기반 살림 현황 대시보드

상태: 사용자 결정 채택 · 날짜: 2026-11-01

## 배경

SallimBook은 매달 빠짐없이 채워야 하는 가계부가 아니다. 부부가 등록한 자산·계좌·카드·보험·가전과 월 계획을
바탕으로 우리 집의 현재 살림 현황을 바로 보는 것이 목적이다. 그동안 홈은 선택한 달의 월 기록이 없거나
확정되지 않으면 자산 현황 대신 작성·확정 안내를 앞세웠다. 기록이 100% 최신이 아니어도 현황은 보여야 하고,
갱신은 사용자가 필요할 때 스스로 한다.

## 결정

1. 홈 상단은 등록한 기록으로 계산한 **현재 살림 현황**이다. 월 기록의 작성·확정 여부와 관계없이 표시한다.
2. 자산·부채는 항목마다 **마지막으로 직접 입력하거나 확인한 금액**과 그 기준 월을 쓴다. 이전 달에서 이어 온
   뒤 확인하지 않은 값은 새 기준이 아니므로 원래 입력한 달을 기준 월로 보여 준다. 선택한 달 이후의 기록은
   쓰지 않는다.
3. 금액을 입력한 적 없는 항목은 합계에서 빼고 "금액 미입력 N개"로만 알린다. 매달 바뀌는 금융·대출 항목은
   마지막 입력·확인이 3개월 이상 지났으면 "오래된 금액"으로 알린다. 부동산·보증금처럼 천천히 바뀌는 평가액은 오래됐다고
   표시하지 않는다. 알림은 현황을 가리거나 입력을 강요하지 않는다.
4. 계좌는 연결된 자산 한 행으로만 합산한다. 계좌 잔액과 자산 평가액을 중복 합산하지 않는다.
5. **월 계획 기준 여유**는 확인된 예상 수입에서 소비성 비용과 대출 원리금을 뺀 값이고, 이체 후 여유는 연금
   납입·저축 같은 자산 이동까지 뺀 값이다. 실제 잔액·저축액이 아니며 그렇게 표시하지 않는다. 금액 미정
   항목과 예산 제외 금액은 따로 보여 준다.
6. 일부 영역을 불러오지 못해도 나머지 현황은 그대로 보여 주고, 실패한 영역만 다시 불러올 수 있게 한다.
7. 월 확정·월간 비교·재개방은 그대로 유지하는 선택 기능이다. 현황 조회는 어떤 월 기록도 만들거나 바꾸지
   않으며, 수입·보험금·고정 납부로 스냅샷을 자동 가감하지 않는 원칙도 그대로다.

## 결과와 비용

월 기록을 다 채우지 않아도 홈에서 우리 집 상태를 볼 수 있다. 대신 표시한 금액이 서로 다른 달 기준일 수 있으므로
각 항목의 기준 월과 가장 오래된 기준 월을 함께 보여 준다. 계산은 서버 `GET /api/v1/household-overview`가 맡고,
UI는 받은 십진 문자열을 표시만 한다.

## 검증

공통 계산 예제는 `packages/test-fixtures/household-overview.json`이다. 서버 DB 테스트
`services/api/tests/test_household_overview.py`가 최신 입력 금액·중복 없는 계좌 합산·월 계획 기준 여유·가계
범위를 확인하고, Android JVM 테스트 `HouseholdOverviewPolicyTest`가 네이티브 응답 형식을 확인한다. 화면 동작은
Playwright 홈 테스트로 확인한다. 실기기 확인은 별도다.
