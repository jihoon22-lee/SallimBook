# ADR 0006 — 계정·앱 잠금·암호키 복구 분리

상태: 설계 채택 · 날짜: 2026-10-17 · 구현 검증 전

## 배경

지문 인증 성공만으로 서버 로그인이나 암호키가 자동 생기는 것은 아니며 공유 vault의 복구가 필요하다.

## 결정

서버 계정 인증/패스키, 로컬 앱 잠금, Keystore 또는 보관함암호 기반 비밀해제를 구분한다. 계정 복구와 HVK 복구를 분리한다.

## 결과와 비용

기기 분실·지문 변경·서버 계정 복구를 서로 독립적으로 처리할 수 있다. 보관함 암호/복구코드/신뢰기기가 모두 없으면 비밀 복원이 불가능함을 안내해야 한다.

## 검증

관련 요구사항의 인수 기준과 보안 게이트를 따른다. 결정 변경은 새 ADR로 기록하고 기존 문서를 무단 삭제하지 않는다.
