# 등록 내용 중심 가계 대시보드 (#184)

사용자 요청에 따라 홈의 중심을 등록된 자산·계좌·보험·가전과 현재 월 수입·지출로 바꾼다. 월 확정과 검토는 선택적 상세 기능이다. 기본정보가 있고 월 금액이 없으면 항목은 표시하고 금액만 미입력으로 둔다. 미확정 월에 저장한 금액도 조회한다.

1. 현재 예상 월 수입의 서버 합계와 구성원 소계를 기존 수입 요약 계약에 추가한다. 선택월 실제 입금과 분리하며 과거 실적으로 소급하지 않는다.
2. 홈과 수입 첫 화면에 예상 수입을 표시한다. 자산/계좌 목록에 선택월 저장 금액과 기준일을 표시한다. 목록의 바로 입력은 기존 월 작성본을 불러오고 없는 달만 복사 없는 작성본을 준비한다. 금액 저장은 기존 If-Match/가계 권한을 따르며 확정 기록은 재개방 경로를 안내한다. 홈에는 등록 항목별 미리보기와 바로가기를 둔다.
3. 월 마감·검토는 접힌 상세로 이동한다. 교체·보험금 신규 입력·고정비 일반 변경의 클라이언트 전용 확인란을 제거한다. 보관함 인증, 실제 중복, 409 충돌, 삭제/무효 등은 유지한다.
4. 예상 수입의 일반 수정은 사유를 선택 입력으로 바꾸고 기본 감사 사유를 기록한다. 실제 금액/날짜/버전 검증은 유지한다.
5. 합성 API 권한/집계, 웹과 Android 계약/흐름 회귀를 검증한다. 생성 계약·제품 문서를 함께 갱신한다. 실제 사용자 데이터는 재입력하거나 테스트에 복사하지 않는다.

기존 요구사항의 월 확정은 비교 기록의 보존 규칙으로 유지한다. 보유 현황 조회의 전제 조건으로 요구하지 않는다. 보험 보장액과 가전 구매가는 자산 합계에 임의로 더하지 않는다.

Android 홈의 동시 조회는 네이티브 8개 요청 한도를 넘지 않도록 최대 4개씩 처리한다. 대기 중 로그아웃·잠금·세션 변경이 발생하면 실행 직전 세대를 확인해 이전 조회를 폐기한다. 쓰기와 인증 작업을 자동 재시도하거나 대기열에 넣지 않는다.
