# ADR 0002 — 월간 스냅샷 우선·부분 금전 기록

상태: 설계 채택 · 날짜: 2026-10-17 · 구현 검증 전

## 배경

v1에 금융 자동 수집이나 전체 거래내역이 없지만 자산 변화를 확인해야 한다.

## 결정

확인한 월별 잔액/평가액을 기준 원본으로 둔다. 수입·의료비·고정납부·보험금은 제한된 별도 사실 기록이다.

## 결과와 비용

입력 부담을 줄이고 실제 사용을 시작할 수 있다. 등록 수입에서 실제 총소비/저축을 역산하지 않으며 기록을 계좌잔액에 자동 더하지 않는다.

## 검증

관련 요구사항의 인수 기준과 보안 게이트를 따른다. 결정 변경은 새 ADR로 기록하고 기존 문서를 무단 삭제하지 않는다.
