# 읽기용 자료와 연간 참고 요약 (P17 / #171)

R-02/R-07/R-08/R-15/R-20/R-22. 기존 내보내기와 같은 재인증·스냅샷·발급 전 권한 재확인,
취소·행/용량/시간 한도를 적용한다. DB 변경은 없다.

## 형식과 범위

`POST /exports`의 선택적 `readable`에 영역 목록과 시작/종료일, 선택적 연도를 전달한다.
선택 영역은 자산·계좌·카드·수입·고정 납부·보험·가전/소모품이다. ZIP의 `readable/index.html`을
오프라인 브라우저로 열거나 인쇄한다. 외부 리소스와 스크립트 없이 모든 사용자 문자열을 이스케이프한다.
사람과 연결 대상은 현재 이름, 월 자산값의 명칭은 당시 기록, 시각은 Asia/Seoul로 표시한다. 원래 날짜만 있는 기록에는 시각을 만들지 않는다.
미입력과 0원은 다르다. 이름이 같아도 각 기록을 합치지 않는다.

읽기용 기본정보는 기간과 무관하며, 날짜가 있는 사실·예정 회차와 월 자산값에는 기간을 적용한다.
일자 미상인 월 기록은 선택 기간과 겹치는 월이면 포함하고 월 단위임을 표시한다.
자산값은 각 월의 현재 리비전만 출력한다. 취소·무효 현황과 입고/교체 취소 여부를 표시하며 과거 정정 리비전은 원본 자료에서 확인한다.
JSON/CSV를 함께 선택하면 기존의 **전체 영역·전체 기간 원본**을 그대로 포함한다.
읽기용 범위가 원본이나 별도 선택 문서의 범위를 제한하지 않는다. 읽기용만 선택할 수도 있다.

## 연간 정산

보험 영역 선택 시 선택한 한 해의 1월 1일~12월 31일 **실제 현금 날짜** 기준 요약을
`readable/annual.html`에 별도로 제공한다. 상세 자료의 기간과 구분해서 연간 범위를 명시한다.
환자별로 의료비 지불−환불=순의료비, 실제 보험금 배분−반환=순보험금,
순의료비−순보험금=순부담을 정수 원 단위로 계산한다. 과거 연도 지불의 올해 환불/반환은 올해에만 반영하며
음수 결과를 0으로 바꾸지 않는다. 무효 원본은 제외한다. 청구 연결·청구액·결정액은 합산하지 않는다.
가족 대상과 로그인 구성원을 구분하고 종료한 가족도 기록이 있으면 포함한다.
미배분 보험금은 가족에게 추측 배분하지 않고 별도 표시한다.

보험료는 실제 고정 납부 중 소비성 납부이며 분류가 `보험료`이거나 보험료 규칙 연결 이력이 있는 것,
연금은 분류가 `연금`인 자산 이동으로 한정한다. 다른 자산 이동·원금 상환과 나머지 소비성 납부를 별도 표시한다.
분류·연결이 없는 사용자 입력을 상품명으로 추측하지 않는다. 보험료·연금은 환자별 순부담에 더하지 않는다.
등록된 실제 기록에 대한 참고자료이며 전체 금융 거래·세금 신고 자료 또는 세액 공제 추정이 아니다.

## 검증 계획

합성 데이터로 가족/가계 격리, 복수 청구, 부분 배분, 과거 연도 환불·반환, 무효/정정,
월 기록 경계, 큰 정수·0/미입력, HTML 이스케이프·외부 요청 차단, 원본 불변,
용량/권한/재인증, 웹·Android 선택과 저장, 실제 HTTPS를 검증한다. 실행 결과는 완료 후 기록한다.
