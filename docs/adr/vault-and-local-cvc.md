# ADR 0004 — 공유 카드 보관함·Android 로컬 CVC

상태: 설계 채택 · 날짜: 2026-10-17 · 구현 검증 전

## 배경

부부가 전체 카드번호·유효기간을 보되 기본 마스킹과 재인증이 필요하며 CVC 저장 위험이 다르다.

## 결정

PAN/유효기간은 클라이언트 암호화 공유, CVC는 Android 개인기기 직접입력/암호화만 허용한다. 서버·PC·백업에 CVC 경로를 만들지 않는다.

## 결과와 비용

웹과 앱의 핵심 데이터는 공유하지만 CVC는 기기마다 입력해야 한다. 개인용이라는 이유로 표준상 허용/안전을 단정하지 않고 보안 게이트를 둔다.

## 검증

관련 요구사항의 인수 기준과 보안 게이트를 따른다. 결정 변경은 새 ADR로 기록하고 기존 문서를 무단 삭제하지 않는다.
