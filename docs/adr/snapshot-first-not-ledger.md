# ADR 0002 — 월간 스냅샷 우선·부분 금전 기록

상태: 설계 채택 · 날짜: 2026-10-17 · 구현 검증 전

## 배경

v1에 금융 자동 수집이나 전체 거래내역이 없지만 자산 변화를 확인해야 한다.

## 결정

확인한 월별 잔액/평가액을 기준 원본으로 둔다. 수입·의료비·고정납부·보험금은 제한된 별도 사실 기록이다.

## 결과와 비용

입력 부담을 줄이고 실제 사용을 시작할 수 있다. 등록 수입에서 실제 총소비/저축을 역산하지 않으며 기록을 계좌잔액에 자동 더하지 않는다.

## 검증

관련 요구사항의 인수 기준과 보안 게이트를 따른다. 결정 변경은 새 ADR로 기록하고 기존 문서를 무단 삭제하지 않는다.

## SB-012 구현 결정 · 2026-10-18

종료일이 속한 달에는 최종 확인치를 수동 입력하고 다음 달부터 작성 대상에서 제외한다. 종료 이벤트만으로 0원을
생성하지 않는다. 월말과 다른 기준일은 확정 전에 별도 확인한다. 원본 금전 이벤트로 월 평가액을 가감하지 않는다.

확정 이력은 당시 이름·소유자·지분·입력 기준까지 동결한다. 정정 시 이전 값과 범위를 복사한 새 revision을 만들며,
사용자가 현재 범위 동기화를 선택하지 않는 한 오늘의 지분을 과거 값에 적용하지 않는다. 동일 범위 비교에서는 지분이
변한 항목을 제외하고 전체 증감과 범위 변경 사유를 따로 표시한다.

가계 범위 잠금과 revision/값 UUID·version을 함께 확인하고, 확정된 revision과 값에는 DB 변경 차단 trigger를 둔다.
합성 API 테스트로 미확인·0원·정정·직접 덮어쓰기 거부와 동시 확정/수정·재전송을 검증한다. 화면/실기기 인수는 별도다.
